# Module 7, Lesson 24 — Review Checklist

## Sample project

- [ ] The sample project has two deliberate weaknesses and a committed baseline tag.
- [ ] The reset script restores the baseline exactly, and `git status` confirms it.

## Tasks

- [ ] There are ten tasks, covering reads, edits of several sizes, the shell, a refusal, a long session, and a skill if I built one.
- [ ] Each task has a check a script can run, and each check was tested on the baseline.

## Measurement

- [ ] The results table has every column for every task, in every run.
- [ ] Prompt counts come from the decision log, and I answered prompts as a user would.
- [ ] Each task started from the baseline.

## Change

- [ ] I changed one thing, chose it from the baseline's results, and wrote the expectation before running.
- [ ] The changed version is tagged in the agent's repository.

## Comparison

- [ ] The comparison covers every task, including the ones I did not target.
- [ ] Safety events are compared separately from success.
- [ ] I wrote whether my expectation matched the result.

## Report

- [ ] `REPORT.md` has the five sections in order.
- [ ] Every claim points to a row or a run.
- [ ] The "what is unsafe" section lists events, or says how I checked that there were none.
- [ ] The limits section says what the measurement cannot tell me.

## Reflection

- [ ] I can state the success rate, the token cost, and the safety events of both versions.
- [ ] I can name the first change I would make next, and the number that would show it worked.
