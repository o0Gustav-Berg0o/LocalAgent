# Module 8: Capstone

**Goal:** put the agent on a sample project, measure it on coding tasks with checks, change one thing, measure again, and write an honest report.

**Why a capstone:** every earlier module was tested alone. The capstone asks whether the pieces work together on tasks nobody designed for them, and it asks for numbers instead of impressions.

## Lessons

| Lesson | Title | Time | What you build |
|---|---|---|---|
| 24 | [Capstone: the agent on a sample project, measured](24-capstone/README.md) | about 6 hours | a sample project, ten tasks with checks, two measured versions, and a report |

## Before you start

- Lessons 1 to 23 complete.

## What you have at the end

- A results table for two versions of your agent, on the same tasks and settings.
- A report whose every claim points to a row in that table, and that says what the measurement cannot show.
